# 卡片分析资料包

样本：MIFARE Classic 1K 水卡（UID A1B2C3D4）

| 文件 | 说明 |
|---|---|
| CARD-REPORT.md | 完整技术分析报告（卡型、密钥、字段、校验、滚动码结论） |
| dump_before_197.34.mfd | 消费前二进制 dump（1024 B） |
| dump_after_195.43.mfd | 消费后二进制 dump（1024 B） |
| dump_before_197.34.txt / dump_after_195.43.txt | 同上，十六进制文本 |
| KEY-BLOCK-DIFF.txt | 一次消费引起的变化块 |
| keys_full.mfd | 完整 16 扇区密钥（nfc-mfclassic 格式） |
| keys.dic | 密钥字典（10 把唯一密钥） |

读取方法：`nfc-mfclassic r a u out.mfd keys_full.mfd f`（libnfc 1.7.1 + PN532）

要点：余额 = 扇区2/3 块0 的 [0:2] 小端，单位 0.01 元；[12] 为刷卡次数；[15] 为前 15 字节 XOR。
